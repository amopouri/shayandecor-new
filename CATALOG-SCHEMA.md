# Shayan Decor — Catalog Reference
This is a reference for the supplied catalog CSV. **No product rows are imported.**

Observed fields:
- title / slug / description
- SKU / barcode
- category
- price / previous price / discount
- inventory / quantity / oversell
- cloud image URLs / gallery
- product options: رنگ and سایز
- extra information / specifications
- rug-related data such as شانه where present

The admin product workflow uses these concepts for manual entry.
