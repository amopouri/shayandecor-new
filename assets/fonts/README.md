# Local font slot

Place the final brand font files here, for example:
- `ShayanDecor-Regular.woff2`
- `ShayanDecor-Medium.woff2`
- `ShayanDecor-SemiBold.woff2`
- `ShayanDecor-Bold.woff2`

The shared CSS is intentionally compatible with local WOFF/WOFF2/TTF files.
No binary font is bundled so the package does not ship an unlicensed font.
